# Enterprise CI/CD Automation Platform on AWS

Designed and implemented an enterprise-grade CI/CD automation platform on AWS using Jenkins, GitHub Actions, and ArgoCD.

## Key Features
- Automated CI/CD pipelines for microservices
- Kubernetes (EKS) deployment
- Infrastructure provisioning using Terraform
- GitOps deployment using ArgoCD

## Tech Stack
AWS, EKS, Kubernetes, Docker, Jenkins, GitHub Actions, ArgoCD, Terraform, Linux

## Architecture

- Source code managed in GitHub
- CI pipelines using Jenkins & GitHub Actions
- Dockerized applications deployed to AWS EKS
- Infrastructure provisioned using Terraform
- Continuous deployment using ArgoCD (GitOps)

## Impact
- Reduced deployment time by 40%
- Improved deployment reliability and scalability
- Enabled zero-downtime deployments using kubernetes rolling updates
